# Agent Rules for cod_remidence Project

## Daily Report Automation Rule
Whenever work is done on the project, automatically update or maintain the `dailyreport.md` file in the root directory without needing explicit prompts from the user.

### Daily Report Format:
```markdown
📅 Date: <Date>
👨💻 Name: Aditya Vishvakarma

Work Updates

1=> <Task 1 description>
2=> <Task 2 description>
...
```
- Keep the work updates clear, concise, and structured numbered items starting with `1=>`, `2=>`, etc.
- Always maintain and save daily updates in `dailyreport.md`.
